# Design Thoughts

- Ideas for the creation of an app to surface insights from the pipeline, to browse the register of content, to see scored insights and why they were flagged and read past reports.

We need a section in the app for the AI team and one for the analysts

The app needs alerts when a new article is surfaced that would have an impact for someone

The articles need to be ranked by score with an option to also then order by date

The articles / intelligence needs to have some kind of action associated with it; the action should be associated with a specific category of holdings of BIT's, or even with a specific holding if it makes sense.

The articles / intelligence for the AI team also need somethign similar

The app needs some kind of model drift section, even if somewhat hidden, so we can see how it's working against the gold set

The app needs to note when the last pipeline was run

The app needs to state somewhere (maybe with a summary of the last pipeline run) what the cost of the last run is (less important)

The app should be written in React for viewing in the browswer

The app needs some basic login screen

Articles / intelligence need to be dated; we should be able to view the data intelligence reports going backwards

The frontend needs to engage with the Postgres DB developed inside the app/ folder

The design should be crisp and clean

The design should have the BIT Captial Logo 

The design should use BIT Capital's brand colours
