# Byline extraction — v1

**Task.** Extract the byline of one research article from its HTML.
**Used by.** `research/llm_byline.py`
**Evaluated against.** `research/byline.py` (deterministic parser) over 17 Anthropic
articles, via `research/eval_byline.py`.

**Deliberately untuned.** This prompt was written before seeing the eval result and is
not adjusted to the failure modes the deterministic parser hit. Tuning it against the
gold set would measure the prompt, not the approach. Any later revision goes in `v2.md`
with the diff and its motivation recorded.

---

## System

You extract bylines from research-article HTML. You return only what the document
states. You never infer an author, an affiliation, or a date that is not written in the
page.

## User

Below is the HTML of a research article. Extract its byline.

Return, in the order the page lists them:

- `authors` — one entry per person credited as an author of this article.
  - `name` — the person's name, with any superscript or symbol marker removed.
  - `affiliations` — the organisation(s) this article attributes to that person. If the
    page uses numbered superscripts, resolve them through the page's own footnote
    legend. If the page states a single affiliation for all authors, use it for all. If
    the page states none, use `["Anthropic"]`.
  - `marks` — the symbol markers attached to this author (`*`, `†`, `‡`, …), if any,
    excluding the numeric affiliation keys.
  - `is_fellow` — true if this article presents the person as a fellow, resident,
    intern, or visiting participant in a programme, rather than as a member of staff.
  - `is_anthropic` — true only if this article presents the person as employed by
    Anthropic. A fellowship, residency, internship or collaboration is not employment.
- `date` — the publication date the page states, as `YYYY-MM-DD`. `null` if the page
  states none.
- `star_means` — what this page's own footnotes say the `*` marker denotes:
  `core` (core contributor), `equal` (equal contribution), `fellows` (a fellows or
  residency programme), `other` (defined as something else), or `null` (not used or
  not defined on this page).
- `order_meaningful` — false if the page states the author order is alphabetical or
  otherwise not a credit ordering; true otherwise.
- `no_byline` — true if this page credits no authors at all.

Rules:

1. Only authors of **this** article. Names in the body text, in citations, in
   acknowledgements, or in correspondence footers are not authors.
2. Resolve each superscript against the legend printed on this page. Do not carry over
   a convention from any other page.
3. A name broken across a line break is one person, not two.
4. If you cannot find a byline, set `no_byline` to true and return an empty author list.
   Do not guess from the body text.
